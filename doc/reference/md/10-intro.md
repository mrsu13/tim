\mainpage Обзор TIM

TIM (Terminal Instant Messenger) — учебный сетевой мессенджер, доступный
через обычный SSH-клиент. Сервер написан на C++17 поверх mongoose,
libssh, MQTT (mqtts) и SQLite, со встроенным Tcl-подобным интерпретатором
LIL в качестве пользовательского шелла.

## Что внутри документации

- **Modules / Файлы** — обзор всех публичных классов и заголовков TIM.
- **Namespace `tim`** — пользовательские типы и службы; `tim::p::*` —
  внутренние PIMPL-структуры (включены, чтобы видеть устройство сервисов).
- **Examples / Markdown** — описание ESC-последовательностей,
  гиперссылок в терминальных эмуляторах и прочей фоновой матчасти.

## Главные подсистемы

Сервер однопоточен и крутит два событийных цикла по очереди — mongoose
для MQTT и libssh для SSH.

| Подсистема       | Класс / заголовок                              | Назначение                                                                                       |
|------------------|------------------------------------------------|--------------------------------------------------------------------------------------------------|
| Приложение       | tim::application                               | Точка входа; владеет всеми сервисами; реагирует на SIGINT/SIGTERM.                               |
| SSH-inetd        | tim::ssh_inetd                                 | Слушает TCP-порт, проводит SSH-handshake, ставит tim::prompt_service на каждую сессию.           |
| Терминальный шелл| tim::prompt_service, tim::prompt_shell, tim::vt| SSH-канал → ANSI-эмуляция → Tcl-prompt.                                                          |
| MQTT-клиент      | tim::mqtt_client                               | Подключение к брокеру по `mqtts://`, маршрутизация подписок.                                     |
| База данных      | tim::sqlite_db, tim::sqlite_query              | RAII-обёртка над sqlite3; tim::sqlite_tx — транзакционная гарантия.                              |
| Сервисы данных   | tim::user_service, tim::post_service, tim::reaction_service | Подписываются на свои MQTT-топики и записывают изменения в SQLite.                               |
| Сигналы          | tim::signal, tim::signal_connection            | Шаблонная реализация observer-pattern; RAII-токен подключения.                                   |

## Соглашения

- Класс — публичный API, `*_p.h` — приватная PIMPL-структура; внешний
  класс владеет `tim::pimpl<tim::p::X>` и переадресует на неё операции.
- Сборка идёт с `-fno-exceptions`. Ошибки распространяются через
  возвращаемое значение (обычно `bool`) и логирование через
  `TIM_TRACE(...)`. Уровень `fatal` завершает процесс.
- Все комментарии и Doxygen-описания — на русском; теги Doxygen
  (`\param`, `\return`, `\sa` и пр.) остаются на английском.
