# TIM — Terminal Instant Messenger

Учебный сетевой мессенджер для терминала. Клиентом служит обычный SSH-клиент;
сервер написан на C++17 поверх mongoose, libssh, MQTT (mqtts), SQLite и
встроенного Tcl-подобного интерпретатора LIL.

## Возможности

- **Анонимная идентификация по SSH-ключу.** Первые 16 байт SHA-256 от открытого
  ключа клиента становятся UUID пользователя. Никаких регистраций и паролей.
- **Многопользовательский чат** с произвольным числом одновременных сессий
  (в том числе нескольких сессий от одного и того же ключа).
- **Личный профиль:** ник и иконка (обычно emoji) сохраняются в БД и
  отображаются в чате у всех собеседников.
- **Подписки** на других пользователей: сообщения от тех, на кого вы
  подписаны, помечаются звёздочкой (★) перед именем автора.
- **Реакции** на сообщения с целочисленным весом; уведомления о реакциях
  приходят онлайн.
- **Tcl-скрипты** в командной строке через встроенный интерпретатор LIL.
  Цикл, условие, переменные, пользовательские процедуры — всё доступно.
- **Шифрование на всех границах:** SSH между клиентом и сервером, TLS
  (mbedTLS) между сервером и MQTT-брокером, шифрование базы данных.

## Архитектура

Сервер — однопоточный процесс с двумя событийными циклами, опрашиваемыми
по очереди: mongoose для MQTT и libssh для SSH.

- `ssh_inetd` слушает TCP-порт, через libssh принимает соединения,
  проводит SSH-рукопожатие, проверяет открытый ключ клиента и при первом
  запросе shell создаёт `prompt_service`.
- `prompt_service` оборачивает SSH-канал в стек ввода-вывода
  (`a_io_device` → `ssh_terminal_protocol` → `vt` → `prompt_shell`) и
  поднимает поверх него Tcl-движок. Введённый текст и команды уходят в
  шину MQTT.
- `mqtt_client` подключается к брокеру по `mqtts://` и обменивается с ним
  событиями: `user/connect`, `user/setnick/*`, `user/seticon/*`,
  `user/setpubkey/*`, `user/subscribe/*`, `user/unsubscribe/*`,
  `post/<автор>/<id>`, `react/*/*`, `react_event/*/*`.
- Серверные сервисы `user_service`, `post_service` и `reaction_service`
  слушают свои топики, обновляют SQLite и (для реакций) публикуют
  производные события, по которым клиенты показывают уведомления.

Подробности устройства модулей — в каталоге [`src/`](src/).

## Зависимости

- Linux. Кросс-платформенность — заявленная цель проекта, фактически
  проверяется только на Linux.
- C++17 (gcc или clang).
- libssh 0.10+: `apt install libssh-dev`.
- MQTT-брокер с TLS, доступный по адресу `mqtts://127.0.0.1:8883`
  (например, [Mosquitto](https://mosquitto.org/) с собственными сертификатами).
- Сертификаты `ca-cert.pem`, `cert.pem`, `key.pem` в каталоге
  `<AppLocalData>/tls/` (обычно `~/.local/share/tim/tls/`).

Все остальные внешние библиотеки (mongoose, mbedTLS, SQLite, jsoncpp,
fort, LIL, libutf8) вкомпилированы в репозиторий — см. `src/3rdparty/`.

## Сборка

```sh
./build.sh             # debug-сборка
./build.sh release     # релиз
./build.sh --verbose   # подробный лог компилятора
```

Артефакт — бинарник `tim` в корне проекта.

## База данных

При первом запуске база создаётся автоматически в
`<AppLocalData>/tim.db`. Схема, виды и триггеры лежат в каталоге
[`db/`](db/). Чтобы пересоздать базу с нуля (с удалением всех данных):

```sh
cd db && ./create-db.sh
```

## Запуск

```sh
./tim
```

Сервер открывает SSH-порт **2222** и host-ключ ed25519 в
`<AppLocalData>/ssh/host_ed25519`. Ключ генерируется автоматически
при первом запуске. Подключение клиента:

```sh
ssh -p 2222 anyone@localhost
```

Имя пользователя в команде `ssh` значения не имеет — личность определяется
SSH-ключом клиента. Любой ключ принимается; UUID пользователя выводится
детерминированно из открытого ключа (первые 16 байт SHA-256 с битами
версии 4 и DCE-варианта).

## Команды

Внутри сессии доступны Tcl-команды с префиксом `/`. Любая строка без
префикса — это сообщение, которое отправляется в общий чат.

| Команда                | Описание                                                                 |
|------------------------|--------------------------------------------------------------------------|
| `/setnick <ник>`       | задать ник, видимый другим участникам                                    |
| `/seticon <иконка>`    | задать иконку (одна графема, обычно emoji)                               |
| `/subscribe <uuid>`    | подписаться на пользователя                                              |
| `/unsubscribe <uuid>`  | отписаться                                                               |
| `/subscriptions`       | список тех, на кого подписан ты                                          |
| `/subscribers`         | список тех, кто подписан на тебя                                         |
| `/react [вес]`         | реакция на последнее увиденное сообщение; `0` снимает реакцию            |
| `/clear`               | очистить экран                                                           |
| `/puts <текст>`        | вывести текст в свою сессию (не уходит в чат)                            |
| `/palette256`          | напечатать палитру цветов текущего терминала                             |
| `/quit`                | завершить текущую сессию (сервер продолжает работать)                    |

**Ctrl-C** прерывает выполняющийся скрипт.
**Ctrl-D** закрывает сессию (и тоже прерывает выполняющийся скрипт).

LIL предоставляет стандартный набор Tcl-примитивов: `if`, `while`, `proc`,
`set`, `expr`, `list`, подстановки через `[...]` и `$var` — внутри сессии
можно писать полноценные сценарии.
